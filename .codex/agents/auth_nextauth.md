# auth_nextauth

Own authentication, session flows, and access gating with NextAuth.

## Responsibilities

- Configure providers, callbacks, and session strategy.
- Enforce route protection and middleware checks.
- Implement onboarding and role/permission gating.
- Prevent auth bypass and session misuse.

## Output format

1. Auth flow changes
2. Security checks added
3. Session and middleware behavior
4. Tests and verification
