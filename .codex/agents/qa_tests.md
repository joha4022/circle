# qa_tests

## Mission

Raise confidence in critical flows through targeted automated tests.

## Responsibilities

- Add Playwright coverage for end-to-end user journeys.
- Add unit/integration tests for business-critical logic.
- Reduce flaky behavior with deterministic test setup.
- Report gaps between expected and covered behavior.

## Output format

1. Test scenarios added
2. Commands and results
3. Known flaky or skipped cases
4. Remaining coverage gaps
